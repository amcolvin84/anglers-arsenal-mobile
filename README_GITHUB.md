# Angler's Arsenal - Mobile App

React Native mobile application for fishing gear management, ready for Google Play Store.

## Quick Setup for Publishing

### 1. Prerequisites
- Expo account at [expo.dev](https://expo.dev) 
- Google Play Console account ($25) at [play.google.com/console](https://play.google.com/console)

### 2. GitHub + Expo Build Process

**Step 1: Connect to Expo**
1. Go to [expo.dev](https://expo.dev) and sign in
2. Create new project: "Angler's Arsenal"  
3. Connect this GitHub repository

**Step 2: Build for Google Play**
1. In Expo dashboard, select your project
2. Go to "Builds" section
3. Click "Build for Android"
4. Select "Production" profile
5. Wait for build to complete (15-20 minutes)
6. Download the .aab file

**Step 3: Submit to Google Play Store**
1. Upload .aab file to Google Play Console
2. Complete store listing with provided assets
3. Submit for review

### 3. Local Development (Optional)

```bash
npm install -g @expo/cli
npm install
expo start
```
